# ascii-art.de collection (reference copy)

Downloaded 2026-10-22 from the **ASCII Art Dictionary / Collection** at
https://www.ascii-art.de/ascii/ (collection last updated there in July 2005): 2316 subjects, every
`.txt` page linked from its alphabetical index pages (A-B, C, D-F, G-I, J-L, M-O, P-R, S, T, U-W, X-Z).

- `a-b.txt` ... `x-z.txt`: the art, one file per index section. Each subject starts with a `=====` header
  (its name and the address it came from), then the art exactly as published.
- `INDEX.md`: every subject, alphabetical, with its file and line.

**Copyright.** This is a private reference for NeoN+1's art (corp intros, logos, ideas), not ours to
ship. The pieces belong to their artists: most carry the artist's initials or a signature (jgs, hjw,
dwb...); keep them. Before putting a piece (or a close copy) in the game, check the site's copyright
page (https://www.ascii-art.de/info/copyright/) and credit or ask the artist. Using them for inspiration
and drawing our own is the safe path.
