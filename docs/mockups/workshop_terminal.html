WORKBENCH TERMINAL

The keyboard concept, two ways. Left: the half-way version keeps chunky keys but dresses everything else in the game's text style. Right: everything on the game's own 36 x 34 cell grid, drawn the way the game draws (header, tabs, separators, list rows, box buttons). Both work: tap keys to type, drag a key up into a slot, tap a suggestion, switch tabs.

1 · HALF-WAY

Real keys you can drag. The game's header, tabs, separators and lists around them; prompt slots drawn like board nodes.

2 · ALL CELLS

Every character on the grid. Keys are 2 x 2 cells (letter, count in hex like the belt). The count only fits 10 keys a row with 1-cell gaps.
NOTES
The game already has a LOCKER: at cash out you keep one mod for the next run, a step lower (engine/run.js openLocker). The workshop's 5 slots would replace or grow that one.
All cells: the screen is a full-screen panel (no tray), like the LOCKER and THE BOARD. Tabs are the codex's [LABEL] row. Counts are hex (x10 = A), like gear stacks on the belt.
Quest letters (G 0 D) get their own row of gold keys over the keyboard when you have them.
